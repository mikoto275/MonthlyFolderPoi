# 月別フォルダへポイ

写真・動画ファイルを、日付をもとに
月別フォルダへ自動で振り分けるツールです。

ファイル名の日付のほか、
写真に記録されたEXIF撮影日時や、
ファイルの作成日時・更新日時を振り分け基準として使用できます。

「2026年08月」のような月別フォルダを自動で作成し、
写真や動画を年月ごとに整理します。

## 主な機能

- ファイル名／EXIF撮影日時／作成日時／更新日時から振り分け基準を選択
- 「2026年8月」のような月別フォルダを自動作成
- 既存の月別フォルダへの振り分けに対応
- 対象ファイルを一括で振り分け
- 指定した月のみの振り分け
- 振り分け前に対象月・ファイル数を確認
- 同名ファイルが存在する場合は上書きせずスキップ
- 対象フォルダを記憶して次回起動時に復元

## 使用例

振り分け前

2026-07-15 12.34.56.jpg  
2026-08-01 10.20.30.jpg  
2026-08-02 18.30.00.mov

振り分け後

2026年7月  
└ 2026-07-15 12.34.56.jpg

2026年8月  
├ 2026-08-01 10.20.30.jpg  
└ 2026-08-02 18.30.00.mov

## 対象ファイル

以下の日付情報を振り分け基準として選択できます。


【ファイル名】

ファイル名の先頭にある「YYYY-MM-DD」形式の日付を使用します。

例）

2026-08-01 12.23.50.jpg

2026-08-15 18.30.00.mov

【EXIF撮影日時】

写真ファイルに記録されているEXIF情報から、
撮影日時を取得して振り分けます。

デジタルカメラなどで撮影した、
ファイル名に日付が含まれていない写真の整理にも利用できます。

【作成日時】

ファイルの作成日時を使用して振り分けます。

【更新日時】

ファイルの更新日時を使用して振り分けます。

選択した振り分け基準から日付を取得できないファイルは、
振り分け対象になりません。
