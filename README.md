# 月別フォルダへポイ

ファイル名の日付をもとに、写真・動画ファイルを
月別フォルダへ自動で振り分けるWindows向けGUIツールです。

## 主な機能

- ファイル名の日付（YYYY-MM-DD）から年月を自動判定
- 「2026年8月」のような月別フォルダを自動作成
- 既存の月別フォルダへの振り分けに対応
- 対象ファイルを一括で振り分け
- 指定した月のみの振り分け
- 振り分け前に対象月・ファイル数を確認
- 同名ファイルが存在する場合は上書きせずスキップ
- 対象フォルダを記憶して次回起動時に復元

## 使用例

振り分け前

2026-07-15 12.34.56.jpg  
2026-08-01 10.20.30.jpg  
2026-08-02 18.30.00.mov

振り分け後

2026年7月  
└ 2026-07-15 12.34.56.jpg

2026年8月  
├ 2026-08-01 10.20.30.jpg  
└ 2026-08-02 18.30.00.mov

## 対象ファイル

写真・動画ファイルを対象としています。

ファイル名の先頭が以下の形式になっているファイルを振り分けます。

YYYY-MM-DD

例：

2026-08-01 12.23.50.jpg

## ダウンロード

## 動作環境

Windows 10 / 11（64bit）
